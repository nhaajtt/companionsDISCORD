Are the bots okay?

A tiny health check, with no names attached.

S-01

Status

Totals only
no names, no ids, no messages

These numbers are totals only: no server names, no ids and no messages. They come from an optional read-only /status.json that the bot can serve. Until a status address is configured, this page shows clearly labelled sample data.

S-02

Turning it on

Optional
off unless you ask for it

  1. Set a port

    Add this line to .env and restart the bots:

    STATUS_PORT=8788

  2. Keep it local

    The endpoint listens on 127.0.0.1 only, so nothing is exposed to the internet by default.

  3. Publish it with a tunnel

    To show it on a website, put a tunnel in front of that port. The tunnel is what makes it public, and it is your call.

  4. Point the page at it

    Set the address in the data-url attribute of the #live element on this page (or define window.STATUS_URL). Until then, the sample data stays on screen.

Nothing in /status.json identifies a person, a server or a message. More on the privacy page.
