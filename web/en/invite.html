Invite helper

Discord has no way to invite a whole flock of bots in one go. So this page makes it one click per bot, and all you do is press Authorize. A big flock still means some clicking, but at least no copying links by hand.

S-01

Paste and invite

One row per bot
one click per row

Paste Application IDs ONLY. NEVER paste a bot token.

An Application ID is a long number and it is public; anyone can see it. A token is the long text with dots in it. Whoever has a token controls that bot.

If you paste a token by mistake, the box shows a red message and drops it, never stored and never displayed. Even so, if a token has leaked anywhere, reset it in the Developer Portal.

0 bots

    "Open all" opens the links one after another, about 0.7 seconds apart. Browsers may block the extra pop-ups: if so, allow pop-ups for this site, or use the "Open invite" button on each row.

    The IDs live in the #ids= part of the page address and in your browser's own storage, so you can bookmark this page or send it to a friend (it contains public IDs only). Nothing leaves your machine.

    S-02

    What the invite grants

    Four permissions, nothing privileged
    and one order worth following

    Each invite asks for exactly five permissions: View Channel, Send Messages, Read Message History, Send Polls and Connect (to sit in voice). No privileged intents. Invite the first bot first, because it hosts the /companions command.

    S-03

    Where do I find the Application ID?

    Two ways
    one needs no typing

    In the Developer Portal

    Open the Discord Developer Portal, pick the bot's application, open General Information and copy the Application ID.

    From your .env file, right on your machine

    Run the command below in the project folder. It prints every invite link and a ready-made bookmark link, straight from .env. It reads the IDs out of the tokens locally; the tokens never leave your machine.

    npm run invites

    Done inviting? Back to the setup page.
